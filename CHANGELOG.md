# Changelog

## v1.4 (experimental)

- Added advanced accessibility interactions: element targeting, long press, double tap, drag and pinch zoom.
- Expanded navigation and screen waiting tools.
- Added clipboard paste, volume/media controls and device status.
- Restricted root command execution to optional, read-only diagnostics.
- Masked password fields in accessibility text and improved stale-element handling.
- Added user-facing consent guidance for sensitive actions.

## v1.3

- Introduced opt-in Vision/SC screenshot analysis on Android 11+.
- Added image input support in the OpenAI, Anthropic and Gemini provider adapters.

## v1.2

- Added floating chat bubble, blue cursor and screen-edge activity effects.
- Improved voice interaction and task cancellation.

> Build verification is not a substitute for testing on a physical device.
